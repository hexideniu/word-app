# 单词本

基于主动回忆和间隔重复的英语词汇教练，AI 文章用于复习后的语境强化。

## 功能

- **今日复习** — 首页直接显示待复习、词库总量和已掌握数量
- **主动回忆** — 先回忆再看答案，通过「忘记了 / 很困难 / 想起来了 / 很简单」反馈记忆结果
- **间隔重复** — 根据反馈安排下次复习时间，而不是只累计生成文章次数
- **查词** — 输入英文单词，调用大模型 API 获取音标、释义、例句
- **单词本** — 收藏单词，支持搜索、删除、重置复习进度
- **生成文章** — 随机选取待复习单词，生成三种风格的英文短文：
  - 深刻故事
  - 有趣对话
  - 新闻资讯
- **复习追踪** — 保留旧数据的等级字段，并新增 `dueAt` 时间调度字段，兼容已有单词本
- **本次复习** — 查看本次选中的单词列表，支持标记「不认识」重置进度或删除单词
- **保存文章** — 生成的文章可保存或复制，方便回顾
- **发音朗读** — 点击喇叭图标朗读单词发音（Web Speech API）
- **多主题** — 6 种主题风格：经典蓝、暗夜模式、薄荷绿、薰衣草、暖阳橙、樱花粉
- **导入/导出** — 支持 JSON 格式导入导出单词本和设置

## 使用

直接用浏览器打开 `word.html` 即可使用。

## Android 版本

### 快速开始

1. **使用 Android Studio**
   - 打开 Android Studio → File → Open
   - 选择项目根目录的 `android` 文件夹
   - 等待 Gradle 同步完成
   - 点击 Run 运行应用

2. **使用命令行**
   ```bash
   # Windows
   android-build.bat build      # 构建 APK
   android-build.bat install    # 安装到设备
   
   # Linux / macOS
   bash android-build.sh build
   bash android-build.sh install
   ```

### 功能特点

- 复用所有网页功能（查词、单词本、生成文章等）
- 本地数据存储，支持离线使用
- 系统级导入/导出文件支持
- WebView 优化配置
- 支持 API 23+ (Android 6.0 及以上)

详细构建和部署说明见 [ANDROID_BUILD.md](ANDROID_BUILD.md)。

首次使用需在设置中配置：
1. API 地址（兼容 OpenAI 格式）
2. API Key
3. 模型名称

## 设置项

| 设置 | 说明 | 默认值 |
|------|------|--------|
| API 地址 | 兼容 OpenAI 的 API 端点 | — |
| API Key | API 密钥 | — |
| 模型 | 模型名称 | gpt-4o-mini |
| 复习单词数量 | 每次生成文章随机选取的单词数 | 10 |
| 文章字数 | 生成文章的目标英文词数 | 100 |
| 语言难度 | 初级 / 中级 / 高级 | 中级 |

## 技术

- 纯前端，无框架依赖
- 单 HTML 文件，移动端优先
- localStorage 持久化数据
- OpenAI 兼容 API
